Excellent explanation! You accurately distinguished address space isolation, PCB vs. TCB, and correctly noted the TLB cache flush penalty during process context switches.

Model Answer Reference:

A process possesses its own independent virtual address space, files, and PCB. Threads within the same process share that memory space and heap. Consequently, thread switching requires saving only CPU registers and stack pointer, whereas process switching invalidates the MMU's TLB and reloads page directories, incurring major cache penalties.
